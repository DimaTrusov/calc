# Калькулятор

## Описание
Простой калькулятор для выполнения базовых арифметических операций: сложение, вычитание, умножение и деление. Программа позволяет вводить два числа и выбирать операцию, после чего выводит результат.

## Возможности
- Сложение
- Вычитание
- Умножение
- Деление (с проверкой деления на ноль)

## Установка
1. Скачайте или клонируйте репозиторий с калькулятором.
2. Убедитесь, что у вас установлен Python версии 3.x (если калькулятор написан на Python).
3. Запустите файл `calc.py` (или другой основной файл проекта).

## Использование
1. Запустите программу.
2. Введите первое число.
3. Выберите операцию (+, -, *, /).
4. Введите второе число.
5. Получите результат.
